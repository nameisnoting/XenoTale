# 공지사항과 개발자 캐러셀 관리

공지사항은 서버 없이 앱에 포함되는 정적 데이터입니다. `src/content/notices.ts`의 `notices` 배열에 글을 추가하고 배포하면 반영됩니다.

각 글은 `id`(고유하고 변경하지 않는 링크), `category`(`patch` 또는 `other`), `title`, `publishedAt`(시간대 포함 ISO 날짜), `body`(마크다운)를 가집니다. 최신 날짜순으로 표시하며, 목록은 한국 시간 기준 당일 글을 시각으로, 이전 글을 날짜로 표시합니다. 상세 페이지에서는 날짜와 시각을 함께 표시합니다.

글 주소는 `/#/profile/notices/{id}`입니다. 분류 탭은 URL에 남으므로 상세 페이지에서 돌아오거나 새로고침해도 유지됩니다. 글 삭제는 해당 배열 항목 제거로 처리합니다.

개발자 캐러셀은 `src/content/developerCatalog.ts`의 `enabled: false`로 사이트 전체에서 숨겨집니다. 각 기기의 예전 숨김 설정과는 별개입니다. 기존 정원 샘플의 작품 정의와 자동 DB 등록은 서비스 코드에서 제거했습니다. 회귀 테스트용 샘플은 `tests/fixtures/garden.ts`에만 남겨 두었고 배포 번들에 포함되지 않습니다.

이전에 자동 제공한 샘플 카드도 메인과 작품 추가 목록에서 숨깁니다. DB 자체는 삭제하지 않으므로 기존 대화와 백업은 유지됩니다. 직접 소유한 작품 및 샘플 복사본은 숨기지 않습니다.

사용자가 가져오는 작품 파일은 `src/persistence/files.ts`에서 읽고 검증해 브라우저 IndexedDB에 저장합니다. 파일 내용이 앱 소스나 GitHub에 추가되는 구조가 아닙니다.
