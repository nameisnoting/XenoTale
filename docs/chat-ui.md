# 대화방 UI와 연출 편집

제작 페이지의 **대화방 UI**에는 HTML·CSS·JavaScript를 작성합니다.
기본 코드는 다섯 영역에 앱의 실제 컴포넌트를 연결합니다.

| 필수 영역                           | 연결되는 기능                                     |
| ----------------------------------- | ------------------------------------------------- |
| `data-xenotale-slot="header"`       | 방 이름, 이동, 음악, 모바일 로그                  |
| `data-xenotale-slot="workspace"`    | 모든 대화 기능 사이드메뉴                         |
| `data-xenotale-slot="conversation"` | 소설 또는 비주얼노벨, 상태창, 리롤·수정·분기·삭제 |
| `data-xenotale-slot="composer"`     | 입력, 단축어, 모델, 선택지, 전송·중단             |
| `data-xenotale-slot="log"`          | 대화 로그와 사용량                                |

각 영역은 하나씩 있어야 합니다. 일반 `style`에서 그리드, 위치, 크기와 장식을
바꾸고, `style[data-xenotale-native-style]`에서는 연결된 컴포넌트의 색, 테두리,
글꼴, 패딩을 바꿀 수 있습니다. 기능을 숨기는 스타일은 허용되지 않습니다.
글자 크기는 10~40px, 컴포넌트 패딩은 0~32px입니다.
iframe의 `XenoTale.context.uiType`은 `novel` 또는 `visual-novel`입니다.
화면 전환 시 HTML의 `data-ui-type`도 바뀌며 `xenotale-ui-change` 이벤트가
발생합니다. 대화 전송이나 화면 전환으로 제작자 코드의 실행 상태를 초기화하지 않습니다.
`--composer-height`는 앱이 현재 입력 영역의 높이에 맞춰 전달하는 CSS 변수입니다.

모바일에서는 workspace/log를 접을 수 있습니다. 기능은 기존 모바일 메뉴와 로그
버튼으로 계속 접근합니다. 800~1199px에서는 로그를 접을 수 있습니다.
1440px·390px의 소설·비주얼노벨에서 필수 영역, 겹침, 화면 밖 배치와 실행 오류를
확인합니다. 실행 중에도 레이아웃을 확인하고 실패하면 기본 UI를 사용합니다.
방의 **환경 설정 → UI**에서 유형과 **화면 디자인**을 독립적으로 선택합니다.
제작자 UI가 있으면 처음에는 제작자 UI를 사용합니다.

## 검사와 제작완료

UI와 모든 연출의 **유효성 검사**를 통과해야 제작완료가 활성화됩니다.
코드나 등록 리소스가 바뀌면 재검사가 필요합니다. 검사 결과는 작품 파일과 백업에
포함됩니다. 옛 작품 파일은 기본 UI로 계속 읽을 수 있고, 다시 제작완료할 때에는
새 대화방 UI를 검사해야 합니다.

검사는 실행 오류, 필수 기능 영역, 명시적으로 금지한 코드 및 지원 API를 확인합니다.
모든 버튼 조합이나 난독화된 코드의 의도를 증명하는 악성코드 분석은 아닙니다.
실제 격리는 `sandbox="allow-scripts"`, CSP와 제한된 메시지 API로 처리합니다.
제작자 UI에는 화면 유형과 영역 크기만 전달하며 대화, API 키, 저장소와 React 객체는
전달하지 않습니다. URL이 필요한 이미지·음악은 작품에 등록하거나 외부 리소스
입력란에 HTTPS 주소를 한 줄씩 등록합니다. 외부 JS·fetch·폼·상위 앱 접근은 차단됩니다.

## 비주얼노벨

대화 기록을 그대로 사용하고 줄바꿈마다 한 페이지로 표시합니다.
`@이름: 대사`는 이름 탭, `{{user}}`는 해당 장면의 페르소나 이름,
`{{img:1/2}}`는 등록된 이미지로 표시됩니다. 처음에는 작품 표지를 사용합니다.
선택지는 마지막 페이지에 표시하며 입력창에 선택 내용을 넣습니다.
읽던 줄과 입력 초안은 방별로 브라우저에 저장합니다.

## 연출의 화면·음악 변경

기존 `XenoTale.ready/context/screen/complete/close`에 아래 기능을 추가했습니다.

```js
await XenoTale.ready;
await XenoTale.background('1/2'); // 등록된 캐릭터/상황 코드
await XenoTale.music('https://example.com/registered-bgm.mp3'); // null은 음악 끄기
await XenoTale.ui({
  uiType: 'visual-novel',
  theme: { textbox: '#222222', text: '#ffffff' },
});
await XenoTale.complete({ summary: '화면과 음악을 변경했다.' });
```

변경은 실행 중에 미리 보이고 complete 결과와 함께 저장됩니다.
완료하지 않고 닫으면 임시 변경을 취소합니다. 다시 보기는 저장하지 않습니다.
응답을 리롤·삭제하거나 응답 후보를 바꾸면 그 응답에 연결된 연출도 되돌립니다.
이후 챕터나 아이템 강화가 있으면 기존처럼 분기를 사용해야 합니다.
비주얼노벨의 독립 연출 줄은 진입할 때 자동 실행하고, 텍스트와 같은 줄의 연출은
다음으로 넘길 때 실행합니다. 완료 또는 닫기 후 다음 줄로 이동합니다.

챕터·엔딩에는 BGM 주소를 지정할 수 있습니다. 미설정은 이전 노드의 음악을
이어 쓰고, 빈 주소는 음악을 끕니다.
